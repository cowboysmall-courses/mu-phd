# DNA Computing

Collected research and simulations on Molecular / DNA computing

## Setup

Clone the repository as follows:

```zsh

> git clone git@github.com:cowboysmall-courses/mu-phd.git

```

and then move into the root of the repository:

```zsh

> cd mu-phd/

```
